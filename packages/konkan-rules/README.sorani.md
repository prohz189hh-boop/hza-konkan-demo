# پاکەتی یاساکانی HZA KONKAN

ئەم پاکەتە کۆدی تایبەتمەندییەکی بێ‌پەیوەندی و دیاریکراوی TypeScript ـە بۆ یاریی تەختەیی HZA KONKAN. دروستکردنی تەختەکان، ژوکر، پشکنینی گروپ و ڕیز، خاڵدانان، بۆتەکان و ڕێکخستنی ڕاک لەخۆ دەگرێت.

تەنها ناوەڕۆکی `packages/konkan-rules/` بە مۆڵەتی MIT بڵاوکراوەتەوە. سەرچاوەی Unreal، پشتەوەی بەرهەمی، وێنەکان، نیشانە بازرگانییەکان و زانیارییەکانی دامەزراندن لە مۆڵەتەکە دەرەوەن. بۆ تاقیکردنەوە:

```sh
npm install
npm test
```

ئەم وەرگێڕانە بۆ ڕوونکردنەوەی بەڵگەنامەیە؛ وشەکانی یاسا لەگەڵ ناوی کۆددا بە ئینگلیزی هەڵگیراون بۆ ئەوەی واتا جێگیر بێت.
