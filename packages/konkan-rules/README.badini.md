# Pakêta qanûnên HZA KONKAN

Ev pakêt bingeha qanûnên TypeScript a diyarkirî û bê-girêdan e ji bo lîstika tile ya HZA KONKAN. Ew çêkirina tileyan, joker, kontrola kom û rêz, hesabkirina xalên, botan û rêzkirina rackê dihewîne.

Tenê naveroka `packages/konkan-rules/` bi lîsansa MIT tê belavkirin. Koda Unreal, karûbarên backend ên hilberînê, wêneyên, nîşanên bazirganî û hûrguliyên deploymentê li derveyî vê lîsansê ne. Ji bo testkirinê:

```sh
npm install
npm test
```

Ev werger ji bo belgekirina destpêkê ye; navên teknik ên qanûnan bi îngilîzî hatine parastin da ku bi koda pakêtê re hevaheng bimînin.
