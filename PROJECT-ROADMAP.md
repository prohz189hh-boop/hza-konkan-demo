# Roadmap

## Verified foundation

- Native mouse/touch selection, reordering, cross-row insertion, cancellation and invalid-drop recovery.
- Authoritative snapshot presentation, hidden-hand protections, timer and score presentation tests.
- Native auth/profile onboarding, real login and Remember Me restart restoration.
- Native lobby foundation, mode selection, real search/cancel and private-room navigation.

## Immediate work after this demo

1. Retire Moonlit runtime visuals while preserving the lobby state machine and controls.
2. Make local tiles larger, reduce visible gaps and make the base rack less bulky; preserve 30 slots/two rows.
3. Wait for newly approved final art direction before finalizing room/table/rack/tile cosmetics.
4. Extend existing native matchmaking/private rooms, including host-controlled bots using legal server actions.

## Remaining release work

- Four separately authenticated Unreal clients: distinct identities/seats, private hands, full round, scoring and next round.
- Disconnect/reconnect without duplicate seats, rewards or tile actors.
- Parties/friends, progression, deterministic shop/inventory and secure owner entitlement.
- Free starter set; premium tiles 200k–350k, racks 400k–500k, tables 600k–900k coins; about 10% full-bundle discounts.
- Atomic 30-claim daily track: day 1 15k, maximum 30k daily coins, mixed rewards, no missed-day reset, loop after day 30.
- Rate-limited emotes and server-validated rewards; no gambling or pay-to-win.
- Kurdish Sorani (RTL), Kurdish Badini Latin (LTR), Arabic (RTL), English (LTR) through Unreal localization.
- Voice, physical Android testing, performance measurement, Windows/Android packaging and final regressions.

No release date or overall percentage is claimed. Source existence does not mean a feature is integrated or verified end to end.
