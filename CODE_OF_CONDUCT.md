# Code of Conduct

HZA KONKAN welcomes respectful, technically focused collaboration around the MIT-licensed rules package and public documentation.

Participants must be welcoming, considerate, and professional. Do not harass, discriminate against, or threaten anyone; publish private information; impersonate others; or submit malicious code, credentials, or confidential project material.

Maintainers may edit or remove comments, issues, or contributions that violate this standard and may temporarily or permanently restrict participation. Report concerns privately to the repository owner through the contact method listed on the GitHub profile. For suspected security issues, follow `SECURITY.md`.
