# Changelog

All notable changes to the MIT-licensed `@hza-konkan/konkan-rules` package are recorded here.

## [0.1.0] - 2026-10-09

Initial public package release, tagged `v0.1.0`.

- Deterministic 106-tile game model and joker calculation
- Meld validation, opening/Konkan constraints, scoring, and redacted views
- Bot decisions that consume only recipient-safe views
- Match modes and rack ordering helpers
- Node.js tests, TypeScript checking, lint checks, coverage command, and local browser playground
- English, Sorani, and Badini documentation drafts

The package is reusable rules code, not a complete server, Unreal plugin, or production deployment.
